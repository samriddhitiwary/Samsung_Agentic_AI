# Samsung Theme 1 Submission Artifact

Upload the generated MTEB result JSON in the GitHub Release:

- `appsretrieval_results.json`

This file is generated by:

```powershell
python scripts/run_samsung_mteb_submission.py --require-cache
```

The JSON schema is not handcrafted. It is produced directly from:

```python
task_result.to_dict()
```

Runtime artifacts required to reproduce inference on this CPU-only setup:

- local `llama.cpp` embedding server binary
- local `jina-code-embeddings-1.5b-Q8_0.gguf`
- cached embeddings under `data/cache/jina_code_1.5b_full_1024/` or enough runtime to regenerate them

Official guideline provides explicit MTEB JSON generation/upload instructions but does not provide an explicit CSV schema.
